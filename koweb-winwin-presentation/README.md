# KOWEB WIN-WIN SYSTEM — Web Presentation

Static HTML/CSS/JS presentation untuk workshop KOWEB.

## Cara buka lokal
Double-click `index.html`.

## Keyboard
- `→` / `Space` : next slide
- `←` : previous slide
- `N` : speaker notes
- `F` : fullscreen
- `Esc` : close speaker notes / exit fullscreen

## Deploy ke Vercel
1. Upload folder ini ke GitHub, atau langsung drag folder ke Vercel.
2. Framework preset: `Other`.
3. Build command: kosong.
4. Output directory: kosong / default.
5. Deploy.

Karena ini static site, tidak perlu npm install atau build process.

## Edit konten
- Slide: `index.html`
- Style: `css/style.css`
- Navigation + speaker notes: `js/presentation.js`

## Catatan font
Deck memakai Google Font Inter bila ada internet. Kalau offline, otomatis fallback ke Pretendard/Arial.
